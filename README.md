# JEZU HRMS

## Human Resource Management System

JEZU HRMS is a web-based Human Resource Management System built using Laravel and Filament.

It provides a centralized platform for managing employees, departments, attendance, leaves, payroll, employee documents, reports, and company settings.

## Features

- Employee Management
- Department Management
- Attendance Management
- Leave Management
- Payroll Management
- Employee Documents
- Attendance Reports
- Leave Reports
- Payroll Reports
- PDF Export
- Excel Export
- Employee Profile
- Company Settings
- Dashboard Statistics
- Attendance Charts
- Payroll Charts
- Quick Actions
- Role & Permission Management
- Filament Shield Integration
- Responsive Admin Dashboard

## Technologies

- PHP 8.2
- Laravel 12
- Filament 4
- MySQL / MariaDB
- Blade
- Tailwind CSS
- JavaScript
- Livewire
- Vite
- Spatie Permission
- Filament Shield
- Laravel Excel
- DomPDF
